# 迁移前发布内容的输入归档

此目录只用于复现历史内容。新预测使用顶层 `data/` 和 `evaluations/`。

归档 CSV 与顶层数据来自同一来源，沿用 [数据许可](../data/LICENSE)；其余代码和生成结果遵循仓库许可。

`frozen/ic2026_2026-11-03/` 保存原先外层 `data/frozen/` 中的赛果和赛事表，内容未改。该目录的 `backtest.json` 是迁移前外层 `output/backtest.json`（1400 场回测），保存的是当时选参数的依据；它不是用这个冻结数据目录重新计算出的回测。

冻结数据与回测分别沿用当时的输入，不能把两者宣称为同一数据快照的评估。已发布预测结果和视频继续作为历史输出保留，不覆盖成当前模型的结果。

从本次迁移开始，用 Git 提交 SHA 标识数据、模型和评估版本；不再新增长期冻结副本。本目录中的遗留快照不得更新。
