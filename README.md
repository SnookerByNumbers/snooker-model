# 算一杆 · 斯诺克局级实力分模型

B 站「算一杆」和 YouTube「算一杆 SnookerByNumbers」的视频里，赛前预测、赛后对账、实力榜用的都是这个模型。这里公开全部代码和整理好的数据，任何人都可以复现我们的数字，也可以用它算自己关心的比赛。

模型的思路是**按局记账**：一场 6:5 的比赛，不只记"谁赢了"，而是记"赢家赢 6 局、输家赢 5 局"。用近四个赛季的全部职业比赛，给每位球员算出一个实力分。两人的分差决定单局胜率，再按局制换算成整场胜率，最后推演整张签表。

## 能做什么

- **单场胜率**：任意两位球员、任意局制（比如 19 局 10 胜），也能从比赛中途的比分算起。
- **整张签表**：淘汰赛里每位球员每一轮的晋级概率和夺冠概率。
- **实力榜**：全体活跃球员的实力分和误差范围。1500 分是普通职业球员的水平，比对手高 100 分，单局胜率约 64%。

## 快速上手

需要 Python 3.10 以上。

```bash
pip install -r requirements.txt
mkdir -p output

# 1. 回测：逐站模拟"赛前预测"，选出半衰期和往平均拉的力度（约十几秒）
python3 src/model.py backtest data output/backtest.json

# 2. 算一场比赛：特鲁姆普对塞尔比，19 局 10 胜
python3 src/match.py data output/backtest.json "Judd Trump" "Mark Selby" --best-of 19

# 3. 算一整张签表：每人每一轮的晋级概率
python3 src/report.py data examples/draw_ic2026_last16.json output/backtest.json output/forecast.json

# 4. 实力榜
python3 src/ratings.py data output/backtest.json 2026-11-03 output/ratings.json
```

## 原理一页纸

| 步骤 | 做法 |
|---|---|
| 按局记账 | 每场比赛按局数进模型：A 赢下一局的概率 = σ(r<sub>A</sub> − r<sub>B</sub>)，σ 是 logistic 函数 |
| 时间衰减 | 越老的比赛权重越低，按半衰期打折：现在用 1095 天，3 年前的比赛只算一半 |
| 往平均拉 | 加一个 L2 惩罚（λ = 8），比赛少的球员被拉向全体平均，免得几场好球就虚高 |
| 分数尺度 | 换算成类似国际象棋等级分的尺度：1500 = 普通职业球员（近一年打满 40 场的球员的中位数），高 400 分 = 赢面是输面的 10 倍 |
| 误差 | 用拉普拉斯近似算出每人实力分的误差（协方差矩阵），实力榜上的 ± 就是它 |
| 整场胜率 | 单局胜率按"先赢 N 局"的公式换算，同一个实力分适用于任何局制 |
| 签表推演 | 逐轮精确计算每人走到每一轮的概率；再按误差抽 4000 套实力分，每套算一遍，取平均 |

半衰期和 λ 都由回测选出，不是拍脑袋定的。公式和推导见 [模型原理](docs/模型原理.md)。

## 回测成绩

做法：从 2025-07-01 起的 29 站排名赛，每站开打前只用之前的比赛算实力分，再预测这一站正赛的每一场（共 1420 场，不含平局）。

| 模型 | 对数损失（越低越好） | Brier | 看好的一方赢了 |
|---|---|---|---|
| 抛硬币（全部 50%） | 0.6931 | 0.2500 | — |
| 不加衰减、不往平均拉的普通 Bradley–Terry | 0.6231 | 0.2166 | 66.5% |
| **本模型**（半衰期 1095 天，λ = 8） | **0.6223** | 0.2170 | 65.6% |

校准：把每场比赛按"模型给热门的胜率"分组，看热门实际赢了多少。

| 模型给热门的胜率 | 场数 | 平均预测 | 实际 |
|---|---|---|---|
| 50%–60% | 447 | 55.1% | 55.3% |
| 60%–70% | 445 | 64.8% | 64.7% |
| 70%–80% | 349 | 74.5% | 70.2% |
| 80%–90% | 146 | 84.4% | 81.5% |
| 90%–100% | 33 | 92.5% | 100.0% |

70%–90% 这两档，模型给热门的胜率比实际略高。半衰期和 λ 也是在这批回测里选出来的，所以这里的成绩会比真正"没见过"的比赛略好一点。各种设置的完整对比见 [模型原理 · 回测](docs/模型原理.md#回测)。

## 数据

比赛结果整理自英文维基百科的各站赛事页面，覆盖 2023/24 至 2026/27 四个赛季的世界职业斯诺克巡回赛（WST）：排名赛、邀请赛、资格赛、冠军联赛。一共 7761 场比赛、53563 局、301 名球员。怎么抓、怎么解析、有哪些已知问题，见 [数据说明](docs/数据说明.md)。

想用最新的赛果，可以自己重新抓取和解析（见使用指南的"更新数据"一节）。

## 局限

- 只看比分。不知道谁有伤、谁状态好，也没有逐杆数据（进攻成功率、防守、长台）。
- 假设每一局的胜率不变，考虑不到场上的心态起伏和体能。
- 成长期的年轻球员会被低估：他们进步很快，但模型被旧比赛拖住。
- 主场优势：试过给在中国比赛的中国球员加一个主场项，回测反而略差，所以没有采用。
- 数据只来自维基百科页面上写明的比分，个别比赛可能漏记或日期不准（见数据说明）。

本模型只做数据分析，给的是概率，不构成任何建议。
