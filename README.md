# 算一杆 · 斯诺克局级实力分模型

B 站「算一杆」和 YouTube「算一杆 SnookerByNumbers」的视频里，赛前预测、赛后对账、实力榜用的都是这个模型。这里公开全部代码和整理好的数据，任何人都可以复现我们的数字，也可以用它算自己关心的比赛。

模型的思路是**按局记账**：一场 6:5 的比赛，不只记"谁赢了"，而是记"赢家赢 6 局、输家赢 5 局"。用近四个赛季的全部职业比赛，给每位球员算出一个实力分。两人的分差决定单局胜率，再按局制换算成整场胜率，最后推演整张签表。

**视频讲解**：《斯诺克胜率怎么算？5.3万局数据告诉你》，4 分 40 秒讲完模型原理和回测检验。

- B 站：https://www.bilibili.com/video/BV1Gi4t6iE4x/
- YouTube：https://youtu.be/bje8L6Dwedw

## 能做什么

- **单场胜率**：任意两位球员、任意局制（比如 19 局 10 胜），也能从比赛中途的比分算起。
- **整张签表**：淘汰赛里每位球员每一轮的晋级概率和夺冠概率。
- **实力榜**：全体活跃球员的实力分和误差范围。1500 分是普通职业球员的水平，比对手高 100 分，单局胜率约 64%。

## 快速上手

需要 Python 3.10 以上。

```bash
pip install -r requirements.txt
mkdir -p output

# 1. 回测：逐站模拟"赛前预测"，选出半衰期和往平均拉的力度（约十几秒）
python3 -I src/evaluate.py

# 2. 算一场比赛：特鲁姆普对塞尔比，19 局 10 胜
python3 src/match.py data evaluations/backtest.json "Judd Trump" "Mark Selby" --best-of 19

# 3. 算一整张签表：每人每一轮的晋级概率
python3 src/report.py data examples/draw_ic2026_last16.json evaluations/backtest.json output/forecast.json

# 4. 实力榜
python3 src/ratings.py data evaluations/backtest.json 2026-11-03 output/ratings.json
```

第 2 步实时打印两位球员的实力分和整场胜率；使用仓库当前数据，结果随数据提交更新。

球员名用英文，和 `data/matches.csv` 里一致；中文名对照见 `data/names_zh.json`。每条命令的参数、签表配置怎么写、输出文件里每个字段的意思，见 [使用指南](docs/使用指南.md)。

## 原理一页纸

| 步骤 | 做法 |
|---|---|
| 按局记账 | 每场比赛按局数进模型：A 赢下一局的概率 = σ(r<sub>A</sub> − r<sub>B</sub>)，σ 是 logistic 函数 |
| 时间衰减 | 越老的比赛权重越低，按半衰期打折：现在用 1095 天，3 年前的比赛只算一半 |
| 往平均拉 | 加一个 L2 惩罚（λ = 8），比赛少的球员被拉向全体平均，免得几场好球就虚高 |
| 分数尺度 | 换算成类似国际象棋等级分的尺度：1500 = 普通职业球员（近一年打满 40 场的球员的中位数），高 400 分 = 赢面是输面的 10 倍 |
| 误差 | 用拉普拉斯近似算出每人实力分的误差（协方差矩阵），实力榜上的 ± 就是它 |
| 整场胜率 | 单局胜率按"先赢 N 局"的公式换算，同一个实力分适用于任何局制 |
| 签表推演 | 逐轮精确计算每人走到每一轮的概率；再按误差抽 4000 套实力分，每套算一遍，取平均 |

半衰期和 λ 都由回测选出，不是拍脑袋定的。公式和推导见 [模型原理](docs/模型原理.md)。

## 数据与回测的唯一版本

本仓库是模型代码、清洗后数据、回测结果的唯一维护来源。所有更新一起提交到 GitHub；本地仅使用该仓库的工作副本，不再维护外层副本。

**当前数据量、回测成绩、校准表和完整参数网格，统一见 [自动生成的评估报告](evaluations/summary.md)**。原始回测结果在 `evaluations/backtest.json`，数据和代码的 SHA-256 校验值在 `evaluations/manifest.json`。

```bash
# 核对回测是否对应当前代码和数据
python3 -I src/evaluate.py --check
# 更新数据或代码后，重新生成回测、报告和校验记录
python3 -I src/evaluate.py
```

历史修订通过 Git 提交追踪。迁移前已发布预测使用的冻结输入放在 `archive/`，只用于复现历史内容，不用于新预测。此后发布时记录使用的 Git 提交 SHA，无须再复制一套数据。

## 数据

比赛结果整理自英文维基百科各站赛事页面；预测数据覆盖 2023/24 至 2026/27 四个赛季。赛果日期范围和数量见 [当前评估报告](evaluations/summary.md)。抓取、解析规则与已知限制见 [数据说明](docs/数据说明.md)。

## 局限

- 只看比分。不知道谁有伤、谁状态好，也没有逐杆数据（进攻成功率、防守、长台）。
- 假设每一局的胜率不变，考虑不到场上的心态起伏和体能。
- 成长期的年轻球员会被低估：他们进步很快，但模型被旧比赛拖住。
- 主场优势：试过给在中国比赛的中国球员加一个主场项，回测反而略差，所以没有采用。
- 数据只来自维基百科页面上写明的比分，个别比赛可能漏记或日期不准（见数据说明）。

本模型只做数据分析，给的是概率，不构成任何建议。
