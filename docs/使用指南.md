# 使用指南

## 安装

需要 Python 3.10 以上，以及 numpy、scipy；下载数据时还要 requests。

```bash
pip install -r requirements.txt
```

下面的命令都在仓库根目录运行。预测等临时输出放在 `output/`（不进版本库，先 `mkdir -p output`）；当前回测统一放在 `evaluations/` 并提交到 GitHub。

## 第一步：回测，选出参数

```bash
python3 -I src/evaluate.py
```

逐站模拟"赛前预测"，试 42 组参数（半衰期 × λ），外加普通 Bradley–Terry、加主场项、不用冠军联赛这几种变体。每试完一组打印一行，最后写出 `evaluations/backtest.json`、`summary.md` 和 `manifest.json`。运行 `python3 -I src/evaluate.py --check` 可检查数据、代码和评估是否对应。

后面所有命令都从这个文件里取**对数损失最低**的那组参数，所以要先跑这一步。换了数据（比如更新到最新赛果）以后，也要重跑。

`backtest.json` 是一个列表，每组参数一项：

| 字段 | 含义 |
|---|---|
| `half_life` | 半衰期（天） |
| `lam` | 往平均拉的力度 λ |
| `home` | 是否用主场项 |
| `championship_league` | 是否用冠军联赛的比赛 |
| `n_events`、`n_matches` | 回测了多少站、多少场 |
| `log_loss`、`brier`、`accuracy` | 对数损失、Brier 分数、看好的一方赢的比例 |
| `_y`、`_p` | 每一场的实际结果（1 = 前一位球员赢）和预测概率，用于画校准图 |

## 算一场比赛：`match.py`

```bash
python3 src/match.py data evaluations/backtest.json "Zhao Xintong" "Wu Yize" --best-of 11
```

| 参数 | 含义 |
|---|---|
| 两位球员 | 英文名，和 `data/matches.csv` 里一致。名字写错时会提示相近的写法，比如只写 "Trump" 会提示 "Judd Trump"。 |
| `--best-of` | 总局数，例如 11 表示 11 局 6 胜 |
| `--as-of` | 用哪一天之前的比赛算实力分，默认是数据里最后一场比赛的日期 |
| `--score A B` | 比赛进行中：两人已经各赢了几局，从这个比分开始算 |
| `--host-country` | 举办国。只有回测选中主场项时才有用（现在没有选中） |

例如国锦赛 1/4 决赛打到 3:4，赵心童还有多大机会：

```bash
python3 src/match.py data evaluations/backtest.json "Zhao Xintong" "Wu Yize" --best-of 11 --score 3 4
```

输出两人的实力分（± 是 95% 范围）、单局胜率和整场胜率。整场胜率给两个数："with uncertainty" 把实力分的误差也算进去（抽 4000 套实力分取平均），"point estimate" 只用最可能的那套分数。视频里用的是前一个。

## 算一整张签表：`report.py`

```bash
python3 src/report.py data examples/draw_ic2026_last16.json evaluations/backtest.json output/forecast_ic2026_last16.json
```

### 签表配置

```json
{
  "event": "2026 International Championship",
  "as_of": "2026-11-03",
  "host_country": "China",
  "rounds": [
    {"name": "Last 16", "best_of": 11},
    {"name": "Quarter-finals", "best_of": 11},
    {"name": "Semi-finals", "best_of": 17},
    {"name": "Final", "best_of": 19}
  ],
  "draw": ["Stephen Maguire", "Ding Junhui", "Oliver Lines", "Kyren Wilson", "..."],
  "live": [{"p1": "Stephen Maguire", "p2": "Ding Junhui", "f1": 3, "f2": 2}]
}
```

| 字段 | 含义 |
|---|---|
| `as_of` | 用这一天及之前的比赛算实力分 |
| `host_country` | 举办国，只在用主场项时有用 |
| `rounds` | 从第一轮到决赛，每一轮的名字和总局数 |
| `draw` | 按签表顺序列出球员，人数必须是 2 的幂（2、4、8、16、32……）。相邻两人是第一轮的一场，第 1、2 场的胜者在第二轮相遇，依次类推。顺序照维基百科页面上的签表抄。 |
| `live` | 可选。第一轮正在进行的比赛的当前比分，`p1`、`p2` 的先后要和 `draw` 里一致 |

`examples/draw_ic2026_last16.json` 是 2026 国际锦标赛 16 强的签表。**注意**：仓库里的数据已经包含这一轮的赛果（比如马奎尔 5:6 丁俊晖，记在 11 月 3 日），所以这个例子算出来的不是当时的赛前预测，只用来演示用法。真正做赛前预测，要用赛前的数据（见下面"复现和冻结数据"）。

### 屏幕输出

依次打印：

1. 选中的参数和回测成绩；
2. 校准表：模型给热门的胜率分组，对比实际胜率；
3. 第一轮每场的整场胜率和单局胜率；
4. 每人的实力分（± 是一个标准差）、对普通职业球员的单局胜率，以及走到每一轮、夺冠的概率；
5. 敏感性：换成 1 年半衰期、普通 Bradley–Terry、加主场项，夺冠概率各是多少；
6. 主场项的估计值（即使不用，也估一下供参考）；
7. 近一年打满 20 场的实力榜前 25 名。

### 输出文件

| 字段 | 含义 |
|---|---|
| `config` | 用的参数 |
| `players[]` | 每位球员：`elo` 实力分，`elo_sd` 一个标准差，`frame_vs_typical_pro` 对普通职业球员的单局胜率，`matches_past_year` 近一年场数，`point` 和 `odds` 是走到每一轮的概率（最后一项是夺冠），前者只用最可能的分数，后者把误差算进去 |
| `first_round[]` | 第一轮每场：`frame_p1` 单局胜率，`match_p1` 整场胜率（含误差），`match_p1_point` 整场胜率（点估计） |
| `leaders` | 实力榜前 25 名 |
| `backtest` | 选中参数的回测成绩 |
| `home_coef`、`home_coef_sd` | 主场项（不用时为 0） |

## 实力榜：`ratings.py`

```bash
python3 src/ratings.py data evaluations/backtest.json 2026-11-03 output/ratings_2026-11-03.json --since 2026-07-01
```

| 参数 | 含义 |
|---|---|
| 日期 | 截止日 |
| `--since` | 另算一次这一天的实力分，输出里多一列涨跌（例如从赛季开始到现在） |
| `--min-matches` | 近一年至少打多少场才上榜，默认 20；排名概率仅在这些入榜球员间比较 |
| `--draws` | 联合后验抽样次数，默认 20000，至少 1000 |
| `--seed` | 抽样随机种子，默认 0 |

输出里每人有排名、实力分、一个标准差、对普通职业球员的单局胜率、近一年场数、`--since` 那天的实力分。榜单上相邻几名的误差范围常常重叠，名次先后不一定说明谁更强。

少样本诊断新增字段：

| 字段 | 含义 |
|---|---|
| `frames` / `frames_past_year` | 实际用于拟合的总局数 / 近一年局数 |
| `weighted_frames` | 按同一半衰期折算的局数之和；不是独立样本数 |
| `rank` | 点估计排序，保持与原实力榜一致 |
| `rank_mean` / `rank_median` | 联合后验抽样中的平均 / 中位排名 |
| `rank_low` / `rank_high` | 排名分布 2.5% / 97.5% 分位数，约 95% 模型内范围 |
| `top5_probability` / `top16_probability` | 抽样中进入前五 / 前十六的比例 |

抽样保留球员间协方差，不是把每个人的误差条独立抽取。所有统计只用截止日及之前的数据，并遵守冠军联赛开关。排名区间不包含模型设定误差，也未经过独立数据的覆盖率验证；抽样中出现 0% 或 100% 不表示绝无可能或必然。

`src/evaluate.py` 会以数据的最后日期生成统一的 `evaluations/ratings.json`，并将 `small_sample.json`、`small_sample.md` 纳入同一校验清单。后者按每站赛前的折算局数分组审查更强收缩；沿用调参样本，属于探索性分析。

## 在自己的代码里用

```python
import sys
sys.path.insert(0, "src")
from model import Data, fit, race, day
from scipy.special import expit

d = Data("data")
cfg = {"half_life": 1095, "lam": 8, "home": False, "championship_league": True}
t = day("2026-11-03")
mask = d.t <= t
x = fit(d, mask, t, cfg["half_life"], cfg["lam"], cfg["home"])
a, b = d.idx["Judd Trump"], d.idx["Mark Selby"]
p_frame = expit(x[a] - x[b])        # 单局胜率
p_match = race(p_frame, 10)         # 19 局 10 胜
print(f"{p_frame:.3f} {float(p_match):.3f}")
```

`fit()` 返回的数组前 n 项是每位球员的内部实力分（顺序同 `d.players`），最后一项是主场系数。换算成 1500 分制、加误差、推演签表，见 `model.py` 里的 `finish_forecast()`、`covariance()`、`bracket_samples()`。

## 更新数据

```bash
mkdir -p raw
python3 src/fetch_wiki.py raw 2023-24 2024-25 2025-26 2026-27
python3 src/parse_matches.py raw data
python3 src/parse_centuries.py raw data
python3 -I src/evaluate.py
```

- 赛季参数按当前赛季顺延，保持最近四个赛季。
- 维基百科要求接口调用方在请求头里留联系方式。`fetch_wiki.py` 默认填本仓库的地址；你自己运行时，请设环境变量 `WIKI_USER_AGENT="你的工具名/版本 (你的联系方式)"`。
- 一次要下载约两百个页面（脚本每批之间会停半秒），请不要频繁重复下载。
- 解析完先抽查：每站场数是否合理，有没有同一个人被拆成两个 ID，挑几个已知赛果对一下（见数据说明）。

## 复现和冻结数据

预测只取决于三样东西：比赛数据、签表配置、回测选出的参数。随机种子固定，同样的输入每次结果都一样。

更新数据、代码后运行 `python3 -I src/evaluate.py`，核对报告，再将代码、数据和 `evaluations/` 一起提交并推送到 GitHub。发布预测时记录该提交的完整 SHA、签表配置和随机种子。以后通过这个 Git 提交复现，不再维护另一份长期数据副本。

迁移前国锦赛预测的输入保存在 `archive/frozen/ic2026_2026-11-03/`；使用说明见 `archive/README.md`。这些是只读的历史证据，不是当前预测的数据源。历史统计数据在 `data/history/`，预测只读顶层 `data/matches.csv` 和 `data/events.csv`。

## 常见问题

**为什么某位球员不在榜上？** 近一年不到 20 场（`--min-matches`）。他仍然有实力分，`match.py` 可以算，只是误差会大一些。

**新人、业余球员的分数为什么都在 1400 左右？** 比赛少，被往平均拉了。全体球员的平均大约 1400 分，比普通职业球员的 1500 分低。

**能算 Shoot Out、六红球、混双吗？** 数据里没有这些赛事，模型也没为它们调过参数，不建议。

**能算冠军联赛那种小组循环赛吗？** `report.py` 只支持淘汰赛签表。小组赛可以用 `match.py` 逐场算单场胜率；冠军联赛小组赛里的 2:2 平局，可以用单局胜率自己算。
